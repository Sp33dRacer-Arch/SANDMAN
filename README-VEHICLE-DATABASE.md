# SANDMAN Vehicle Database V1

This patch populates the existing `VehicleVariant` catalogue used by SANDMAN Garage.

## Sources
- `SANDMAN_CURATED`: global/SA/EU/JDM supplement.
- `NHTSA_VPIC`: official NHTSA vPIC model-year data.

## Safety
Catalogue presence is not product fitment. Never use a vehicle-catalogue match alone
to claim that an engine part fits. SANDMAN's `ProductFitment` system should remain
the compatibility authority.

See `INSTALL-VEHICLE-DATABASE.txt` for commands.
