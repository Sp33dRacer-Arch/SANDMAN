V3 DEFECTS FIXED FROM THE UNRELEASED V2 REVAMP
1. Messages selector: String.replace interpreted `$$` as a single `$`, binding only one conversation button. V3 uses a replacement callback and preserves the `$$` selector.
2. Startup race: Vinyasa scheduler previously started before curated vehicle bootstrap. V3 starts the scheduler after bootstrap settles.
3. Curated engine loss: engine-coded bundled rows (including B58/N55) previously became UNSPECIFIED. V3 preserves the curated engine field.
4. Fitment axis growth: large make/model/year/engine axes could expand excessively before final slicing. V3 bounds expansion during normalization.
5. Search relevance: V2 could make any photographed result outrank much stronger non-image broad matches and could demote exact-name matches. V3 keeps exact matches first and uses a 45-point image bonus.
