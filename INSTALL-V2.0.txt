SANDMAN V2.0 - SAFE UPGRADE GUIDE
=================================

IMPORTANT
---------
This is a V2.0 upgrade over SANDMAN V1.4.2.
Do NOT copy or commit your .env file.
Do NOT run prisma migrate dev against Railway/production.

1. BACK UP YOUR CURRENT PROJECT
-------------------------------
PowerShell:

Copy-Item "C:\Users\asand\Downloads\SANDMAN-backend" "C:\Users\asand\Downloads\SANDMAN-backend-BACKUP-V2" -Recurse

2. COPY V2 INTO THE BACKEND
---------------------------
After extracting the V2 ZIP, copy its contents over the existing backend.
Example:

robocopy "C:\Users\asand\Downloads\SANDMAN-V2.0" "C:\Users\asand\Downloads\SANDMAN-backend" /E /XD .git node_modules /XF .env /R:1 /W:1

3. INSTALL + VERIFY LOCALLY
---------------------------
cd "C:\Users\asand\Downloads\SANDMAN-backend"
npm install
npx prisma generate
npx prisma validate
npm run typecheck
npm test
npm run build

If Prisma generate reports a Windows EPERM/locked-engine error:
Stop-Process -Name node -Force -ErrorAction SilentlyContinue
npx prisma generate

Do NOT use npm audit fix --force just to make warnings disappear.

4. REVIEW GIT BEFORE COMMITTING
-------------------------------
git status

Make sure .env is NOT staged.
Do not stage extracted duplicate package folders.

Then:
git add package.json README.md CHANGELOG-V2.0.md INSTALL-V2.0.txt VERIFY-V2.0.ps1 prisma public src scripts data tests
git commit -m "Upgrade SANDMAN to V2.0"
git push origin main

5. RAILWAY
----------
Recommended commands:
Build:     npm run prisma:generate && npm run build
Predeploy: npm run prisma:deploy
Start:     node dist/src/server.js

The V2 migration must succeed before V2 request/fitment features are used.
Never replace the production predeploy step with prisma migrate dev.

6. VEHICLE CATALOGUE - ONLY AFTER V2 IS ACTIVE
-----------------------------------------------
Run this INSIDE the Railway SANDMAN service environment:

node scripts/sync-vehicle-catalog.mjs --source=curated --only-make=BMW --from=1996 --to=2027
node scripts/vehicle-catalog-check.mjs

Confirm BMW/M140i works in Vehicle Finder before importing more makes.

7. POST-DEPLOY SMOKE TEST
-------------------------
- /api/health works
- /api reports version 2.0.0
- /api/v2/catalog/status works
- Admin login works
- Admin > Sourcing loads
- Vehicle Finder loads
- My Garage still saves/removes vehicles
- Product page shows verified/catalogue/unconfirmed fitment correctly
- Build page loads and fitment states look correct
- Cart checkout preflight blocks missing fitment/stock problems
- Stripe/PayPal sandbox checkout still works
- Supplier fulfillment still works

PRODUCTION NOTE
---------------
The included static checks do not replace your local dependency-backed TypeScript,
Prisma and test suite. Only deploy after the commands in step 3 pass on your PC.
